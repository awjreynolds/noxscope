# `@noxscope/core`

Platform-neutral Core state, deny-by-default sanitisation, and portable
Recording v1 encode/import/replay. The package accepts canonical data only;
Recordings are local artifacts and replay is operation-free.

Storage drivers and UI controls belong to the Host. See the
[repository README](../../README.md) and
[`REDACTION_AND_RECORDING.md`](../../docs/security/REDACTION_AND_RECORDING.md).
